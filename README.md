# Uniwerek – strona www

Statyczna strona placówki opieki nad dziećmi „Uniwerek” (Stowarzyszenie SOWA), hostowana na GitHub Pages pod https://uniwerek.edu.pl.

- `index.html` – cała treść strony
- `assets/style.css`, `assets/main.js` – style i drobne interakcje (bez frameworków i jQuery)
- `assets/img/` – zoptymalizowane obrazy (WebP), ikony, obraz do udostępnień (og-image)
- `assets/fonts/` – czcionki Fredoka i Nunito hostowane lokalnie

Podgląd lokalnie: `python3 -m http.server 8000` i http://localhost:8000
